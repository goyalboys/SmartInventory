# Return Policy

## Overview

SmartInventory allows returns within a defined window for eligible products.

## Return Window

- **Standard products:** 7 days from delivery date
- **Electronics:** 7 days (must be unused, original packaging)
- **Perishable goods:** Not eligible for return

## Conditions for Return

- Product must be unused and in original packaging
- All tags, accessories, and invoice must be included
- Proof of purchase (order ID) required

## Return Process

1. Initiate a return request via chat or support ticket
2. Receive return instructions and pickup/drop-off details
3. Product is inspected within 3 business days of receipt
4. Refund or replacement is processed after inspection approval

## Return Shipping

- **Defective/wrong item:** Free return shipping (merchant pays)
- **Change of mind:** Customer may bear return shipping costs

## Non-Returnable Items

- Hygiene products (opened)
- Custom/personalized items
- Items marked "non-returnable" on the product page
